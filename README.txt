CLOUDFLARE BUILD SETTINGS
- Production branch: main
- Framework preset: None
- Build command: leave blank
- Build output directory: public

EDIT WORDING OR CONTACT DETAILS
1. In GitHub, open public/index.html.
2. Click the pencil icon.
3. Use your browser's Find command (Command+F on Mac or Ctrl+F on Windows).
4. Search for the existing wording, email address, or phone number.
5. Make the change and click Commit changes.
6. Cloudflare Pages will automatically publish the committed update.

EDIT COLORS
At the top of public/index.html, find :root and change the hex values:
- --ink: primary dark text
- --muted: secondary text
- --cream: hero background
- --paper: main page background
- --sage: soft accent
- --forest: main buttons and dark green accents
- --forest-dark: button hover color
- --gold: gold accent

REPLACE THE PLACEHOLDER IMAGE
1. Upload your new JPG or PNG into the public folder. Example: hero-photo.jpg
2. Open public/index.html and search for hero-placeholder.svg.
3. Replace that filename with hero-photo.jpg.
4. Commit the change.
